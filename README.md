# LM Studio AI ゲームセンター

LM Studio などの OpenAI 互換ローカル LLM API とブラウザから直接ストリーミング通信（SSE）し、AI の思考過程をリアルタイムに見ながら対戦できるボードゲーム＆トランプゲーム集です。ビルド不要のバニラ HTML / CSS / JavaScript で動作します。

## 遊べるゲーム（全10種類）

### ボードゲーム（5種）
- **オセロ (Othello)**: 8×8盤、角・X打ち/C打ち解説付き、1手先読み対応
- **マンカラ (Mancala)**: 6×2ポケット＋2ゴール、連続手番・横取り・2手先連鎖/リスク計算
- **五目並べ (Gomoku)**: 15×15盤、5連即勝・活四・止め四・活三の攻防評価
- **四目並べ (Connect Four)**: 7列×6段、重力落下・即勝利・相手4連阻止・上段献上リスク評価
- **チェッカー (Checkers)**: 8×8盤、強制ジャンプ捕獲・連続ジャンプ・キング昇格対応

### トランプゲーム（5種）
- **ブラックジャック**: 1対1チップ制（ヒット / スタンド / ダブル / ナチュラル21）
- **5カード・ドローポーカー**: 1対1チップ制（カード交換＋チェック / ベット / レイズ / フォールド）
- **大富豪**: 1対1・13枚手札（ジョーカー、8切り、革命、スペ3返し、階段対応）
- **クレイジー8**: UNO風トランプ（8ワイルド＋スート指定、2ドロー、Jスキップ）
- **神経衰弱**: 6×4（24枚・12ペア）、難易度に応じて AI の記憶保持枚数が変化

※トランプ系ゲームは、AI に相手の伏せ札や山札を送信しないフェアな隠匿情報対戦として設計しています。

## 使い方

1. **LM Studio を起動**
   - LM Studio でモデルをロードし、Local Server を起動します（デフォルトポート `1234`）。
   - ブラウザから直接 `fetch` するため、LM Studio 側の **CORS（Cross-Origin Resource Sharing）** を有効にしてください。
2. **アプリを開く**
   - `othello.html` をブラウザで開きます（またはローカル HTTP サーバー経由で配信）。
   - 接続先 URL（デフォルト: `http://localhost:1234/v1/chat/completions`）とモデル、難易度（かんたん / ふつう / つよい / 達人）を選んで対局できます。

## ファイル構成

- `othello.html` — メイン HTML（ゲーム切り替えタブ、設定・盤面・思考ログパネル）
- `styles.css` — 全体および各ゲーム盤面・トランプカードのスタイル
- `js/game-registry.js` — ゲーム登録レジストリ
- `js/cards.js` — トランプ共通ユーティリティ（デッキ・描画・ポーカー役判定）
- `js/engine.js` / `js/mancala-engine.js` — オセロ・マンカラの純粋ルールエンジン
- `js/ai.js` — LM Studio API ストリーミング通信・推論タグ解析・行動抽出
- `js/games/*.js` — 各ゲームのルール・プロンプト・UI 実装
- `js/app.js` — 共通ゲームホスト（セッション保持、待った、中断・再試行・フォールバック）
